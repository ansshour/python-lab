# Больше гостей — больше порций

Рецепт рассчитан на двоих, а за столом четверо? Умножьте количество
каждого продукта на отношение нового числа порций к исходному.

<math xmlns="http://www.w3.org/1998/Math/MathML" display="block" aria-label="Новое количество равно исходному количеству, умноженному на новое число порций и делённому на исходное число порций">
  <msub><mi>m</mi><mn>2</mn></msub><mo>=</mo>
  <msub><mi>m</mi><mn>1</mn></msub><mo>×</mo>
  <mfrac><msub><mi>n</mi><mn>2</mn></msub><msub><mi>n</mi><mn>1</mn></msub></mfrac>
</math>

Здесь **m₁** — исходное количество продукта, **m₂** — новое,
**n₁** и **n₂** — исходное и новое число порций.

Для четырёх порций пасты вместо двух понадобится:

| Продукт | На двоих | На четверых |
| --- | ---: | ---: |
| Паста | 200 г | 400 г |
| Куриное филе | 250 г | 500 г |
| Сливки | 150 мл | 300 мл |
| Сыр | 50 г | 100 г |

Соль и специи добавляйте по вкусу. Время приготовления не нужно
увеличивать вдвое: ориентируйтесь на готовность блюда.

Формула встроена в страницу и не требует загрузки со сторонних серверов.
В браузере без поддержки формул используйте правило:
**новое количество = исходное количество × новые порции ÷ исходные порции**.
